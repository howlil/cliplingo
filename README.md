# ClipLingo

ClipLingo is a Windows-first, offline-first translation utility designed around a fast interaction: select text in another application, press a global shortcut, and read the translation in a lightweight popup near the selection.

The project is intentionally starting from engineering constraints and architecture before implementation. The initial priorities are reliable cross-application text capture, low perceived latency, low idle resource usage, privacy, and strong Chinese/Japanese/Korean support.
