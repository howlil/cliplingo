# ClipLingo 0.1.0 Alpha 2

ClipLingo Alpha 2 changes the primary product path to direct offline English-to-Indonesian translation and makes the application behave like a native Windows background utility.

## What works

- ClipLingo runs from the Windows notification area/system tray.
- Left-click the tray icon to open the compact Settings window; right-click exposes Settings and Quit ClipLingo.
- Select English text in another Windows application and invoke `Ctrl+Alt+T`.
- ClipLingo validates that a non-empty selection exists before any translation popup is shown.
- Invoking the shortcut with no valid selection produces no visible popup and does not start translation.
- Translation executes locally through the pinned OPUS-MT `en -> id` model on CPU.
- The result popup appears near the selected text or cursor fallback and can be dragged by its `EN → ID` header.
- A missing model pack can be installed explicitly and is SHA256-verified before activation.
- Settings exposes the current route, shortcut, model state, model install/remove actions, and explicit application quit.
- Closing Settings keeps ClipLingo running in the system tray.

## UI direction

The popup and settings surfaces intentionally use restrained Windows utility styling: compact spacing, semantic hierarchy, modest elevation, and native light/dark adaptation. Decorative glass blur, gradients, glow, bento/card stacks, oversized radii, and generic AI branding chrome are not used.

## Alpha constraints

- Windows 10/11 x64 is the qualified platform.
- English to Indonesian is the only production translation route in this milestone.
- The release is unsigned, so Windows SmartScreen may warn on first install.
- OCR, cloud fallback, GPU inference, accounts/sync, translation history, configurable shortcuts, and additional language routes are out of scope.

## Release qualification

The release workflow creates this tag only after it builds and validates the pinned `en-id-opus-v1` model pack, builds and executes the native runtime probe, runs a real non-deterministic English-to-Indonesian translation through the isolated worker, and successfully produces the Windows x64 NSIS installer.
